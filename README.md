# ExploreEase 🧭 — Smart Travel Planner for India

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Web%20%7C%20PWA-green.svg)](#)
[![OSRM](https://img.shields.io/badge/Maps-OpenStreetMap%20%26%20OSRM-orange.svg)](#)

**ExploreEase** is an interactive, modern web application designed to help travelers discover authentic attractions, luxury stays, renowned dining spots, and real-time routes across Indian cities.

---

## 🌟 Key Features

- 🏛️ **Curated Cities & Attractions**: Handcrafted, authentic information for tourist landmarks, luxury hotels, and iconic restaurants across Delhi, Mumbai, Jaipur, Agra, Goa, Bengaluru, Varanasi, Kolkata, Amritsar, Udaipur, Manali, Shimla, and Hyderabad.
- 🗺️ **Real-Time Route Planner & Navigation**: Interactive Leaflet & OpenStreetMap routing powered by OSRM. Calculate driving, two-wheeler, and walking distances with turn-by-turn maneuvers and direct Google Maps sync.
- 🌤️ **Live Weather & Travel Seasons**: Instant climate and ideal season recommendations for all major Indian travel destinations.
- 💰 **Smart Trip Budget & Cost Calculator**: Estimate overall trip expenses for 1–7 days across solo, couple, or family travel styles.
- 📄 **Printable / PDF Itinerary**: Generate clean, professional trip confirmation summaries ready for printing or offline PDF saving.
- 📱 **Progressive Web App (PWA)**: Installable directly onto Android and iOS home screens with offline resilience via Service Workers.
- 🔒 **User Authentication & Booking History**: Client-side secure profile editing, feedback collection, and booking logs.

---

## 🚀 Live Demo & Deployment

This project contains pure HTML5, CSS3, and modern Vanilla JavaScript without external build steps. It can be deployed directly via **GitHub Pages**:

1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live within seconds!
